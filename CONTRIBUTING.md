# Contributing

Thanks for your interest in contributing to this repository.

Issues and suggestions are welcome. If you open a pull request, keep it focused, small, and directly related to the purpose of this repository.

Please follow these guidelines:

- Keep contributions within the scope of public educational examples.
- Do not include production code, internal architecture, or private implementation details.
- Do not add secrets, credentials, private URLs, or sensitive data.
- Prefer clear, beginner-friendly code and documentation.

This repository is intended to stay technical, public, and easy to review.
